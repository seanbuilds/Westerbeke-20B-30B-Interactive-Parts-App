# Westerbeke 20B / 30B Interactive Engine Parts App

Interactive single-file HTML app for identifying parts on a Westerbeke marine diesel from the **20B TWO** / **30B THREE** family.

Parts data compiled from **official Pub #037115** (fuel + cooling + block groups) via Westerbeke / Torresen Marine online catalogs.

## Quick start
1. Keep `engine_front.jpg` and `engine_side.jpg` next to the HTML.
2. Open `Westerbeke_Engine_Interactive_Parts_App.html` in a browser.
3. Use **Hoses** / **Clamps** / **Nuts / Washers** chips or click green/blue hotspots.

## Safety
Diesel leaks are a fire hazard. Inspect every hose and clamp before running. Confirm serial plate before ordering. Banjo washers are single-use crush seals. 036868 is listed NLA — verify current supersession with a Westerbeke dealer.
